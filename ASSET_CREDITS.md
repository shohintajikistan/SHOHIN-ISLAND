# SHOHIN MINER — 3D asset notes

The current SHOHIN MINER scene builds its miner characters, clothing colors, helmets, backpacks, and pickaxes directly with Three.js geometry. Their mining motion is animated in the game code. The current version does not download external character GLB files.

The earlier external-character experiment referenced:
- https://github.com/NoLimitNexus/game-models

That external loader has been removed from the active game because it made visible workers depend on a successful third-party download.

SHOHIN MINER is an independent game project. It does not include Idle Miner Tycoon's proprietary character models, textures, source code, or extracted game files.
