# SHOHIN MINER — 3D asset credits

The miner character body kit, clothing parts, pickaxe prop, and character assembly/animation helper are loaded from the public project:

- Project: https://github.com/NoLimitNexus/game-models
- Character assembly source: https://github.com/NoLimitNexus/game-models/blob/main/character.js
- Model catalog: https://github.com/NoLimitNexus/game-models/blob/main/library/ours/manifest.json
- Miner preset reference: https://github.com/NoLimitNexus/game-models/blob/main/library/ours/presets.json

The project README identifies the character body kit as original assets made by the repository authors. It identifies the shared KayKit animation clips and Rig_Medium skeleton as CC0 assets by Kay Lousberg.

- Animation catalog: https://github.com/NoLimitNexus/game-models/blob/main/library/animations/roles.json
- Kay Lousberg: https://kaylousberg.com/

SHOHIN MINER uses the miner outfit parts and pickaxe, recolored in SHOHIN green and gold. The app loads the GLB models and the mining animation over the internet from the project's jsDelivr mirror. A network connection is required to load these external assets.

This is an independent game project. It does not include Idle Miner Tycoon's proprietary character models, textures, source code, or other extracted game files.
