# SHOHIN MINER — Game Design

## Core identity
A premium 2.5D underground idle mining tycoon under the SHOHIN TAJIKISTAN brand.

## Visual direction
- Side-on underground mine cross-section.
- Dark rock, timber and metal structures.
- Warm amber work lights, subtle dust and restrained emerald/gold UI.
- Clear silhouettes and readable equipment.
- Avoid heavy real-time 3D rendering; prioritize stable performance on mid-range Android phones.

## Core loop
1. Miners extract ore.
2. The elevator transports ore.
3. The warehouse stores it.
4. Ore is sold for cash.
5. Cash upgrades production and transport.
6. Production continues while the game is closed, using a capped offline reward.

## First playable milestone
- One coal mine level.
- Three miners.
- Manual collect/sell action plus automatic production.
- Upgrade miner speed, elevator capacity and warehouse capacity.
- Save progress locally.
- Mobile-friendly interface.

## Planned expansion
- Ten initial underground floors.
- Coal, copper, iron, gold and diamond deposits.
- Managers, missions, achievements and prestige.
- Additional mines and deeper layers.
